# Доступ к запущенному сайту

## Локальная разработка

```bash
npm run dev
```

Сайт доступен по адресу `http://localhost:3000`.

## Docker

По умолчанию Compose публикует порт только на loopback-интерфейсе:

```text
http://127.0.0.1:3000
```

Для доступа из доверенной локальной сети задайте `HOST_BIND_ADDRESS=0.0.0.0` в `.env`. Не используйте этот режим для прямой публикации в интернет.

## Временный внешний доступ

Туннели передают трафик стороннему провайдеру. Не отправляйте через временный туннель реальные заявки и персональные данные без проверки условий провайдера.

Для локального демо можно использовать `./start-ngrok.sh`. Остановите туннель сразу после демонстрации.

## Production

Рекомендуемая схема:

```text
Internet → HTTPS reverse proxy / managed platform → site_etalon:3000
```

Обязательно:

- HTTPS и актуальный сертификат;
- секреты вне Git и Docker image;
- резервное копирование runtime-хранилища заявок;
- ограниченный доступ к экспорту CSV;
- мониторинг логов и регулярное обновление зависимостей.

Не настраивайте port forwarding домашнего роутера для production-сайта.
