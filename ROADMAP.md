# Roadmap

Roadmap описывает возможные направления развития и не является обещанием конкретных сроков. Изменения планируется вести через отдельные issues и небольшие pull request.

## Базовая готовность open source

- воспроизводимая установка через `npm ci`;
- автоматические lint, typecheck, tests, dependency audit и production build в GitHub Actions;
- правила участия, безопасности и шаблоны обращений;
- исключение сборочных файлов, зависимостей, секретов и персональных данных из Git;
- CodeQL и Dependabot для постоянного контроля безопасности;
- воспроизводимая standalone- и Docker-сборка с документированными переменными окружения.

## Ближайшие улучшения

- расширить автоматические тесты до полных API route и browser-сценариев;
- согласовать и документировать единственный основной канал уведомлений;
- после согласования очистить старую Git-историю от ранее закоммиченных generated-файлов и данных заявок;
- определить, какие исходные JPG/PNG нужны для дальнейшей обработки, а какие можно вынести из основного репозитория;
- оптимизировать крупные изображения без потери качества;
- оформить первые versioned releases и changelog.

## Дальнейшие направления

- отделить хранение заявок от файловой системы через простой адаптер;
- выделить переиспользуемые компоненты формы, валидации и уведомлений;
- добавить пример безопасного развёртывания для других образовательных организаций;
- улучшить доступность и автоматизировать её проверку;
- исследовать помощника по проверенным материалам центра без передачи персональных данных.

Предложения по приоритетам можно создавать через шаблон feature request.
