# Настройка Telegram Bot для отправки анкет

## Шаг 1: Создание Telegram Bot

1. Откройте Telegram и найдите бота @BotFather
2. Отправьте команду `/newbot`
3. Введите имя для вашего бота (например: "Эталон Заявки")
4. Введите username для бота (например: "etalon_penza_bot")
5. Сохраните полученный **Bot Token** (выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

## Шаг 2: Получение Chat ID администратора

### Важно: Chat ID должен быть ID пользователя, а не бота!

1. **Добавьте созданного бота в контакты**
2. **Напишите боту любое сообщение** (например: "Привет")
3. **Откройте в браузере**: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
4. **Найдите в ответе**:
   ```json
   {
     "message": {
       "from": {
         "id": 123456789, // ← Это ID пользователя (нужен этот!)
         "is_bot": false,
         "first_name": "Ваше Имя"
       },
       "chat": {
         "id": 123456789, // ← Это Chat ID (должен совпадать с ID пользователя)
         "type": "private"
       }
     }
   }
   ```

### ⚠️ Важные моменты:

- **ID пользователя** и **Chat ID** должны совпадать для личных сообщений
- **НЕ используйте** ID бота (is_bot: true)
- **Убедитесь**, что вы написали боту сообщение перед получением ID

## Шаг 3: Настройка переменных окружения

Создайте файл `.env.local` в корне проекта:

```env
# Telegram Bot Configuration
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_ADMIN_CHAT_ID=your_admin_chat_id_here
```

## Шаг 4: Проверка работы

1. Перезапустите сервер разработки: `npm run dev`
2. Заполните форму на сайте
3. Проверьте, что сообщение пришло в Telegram

## Формат сообщения

Бот будет отправлять сообщения в следующем формате:

```

👤 *Имя:* Иван Иванов
📞 *Телефон:* +7 (999) 123-45-67
📧 *Email:* ivan@example.com
📚 *Предмет:* Математика

⏰ *Время:* 15.12.2024, 14:30:00

```

## Безопасность

- **НЕ** коммитьте файл `.env.local` в Git
- Храните Bot Token в безопасности
- Регулярно проверяйте логи на предмет ошибок

## Устранение неполадок

### ❌ Ошибка "Forbidden: bots can't send messages to bots"

**Причина**: Chat ID указывает на бота, а не на пользователя
**Решение**:

1. Убедитесь, что вы используете ID пользователя, а не бота
2. В ответе getUpdates найдите `"is_bot": false` - это ID пользователя
3. НЕ используйте ID где `"is_bot": true`

### Ошибка "Bad Request: chat not found"

- Убедитесь, что Chat ID правильный
- Убедитесь, что вы написали боту хотя бы одно сообщение

### Ошибка "Unauthorized"

- Проверьте правильность Bot Token
- Убедитесь, что бот не был удален

### Сообщения не приходят

- Проверьте консоль браузера на ошибки
- Проверьте логи сервера
- Убедитесь, что переменные окружения загружены правильно
