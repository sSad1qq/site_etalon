# Участие в разработке

Спасибо за интерес к проекту «Эталон». Мы приветствуем сообщения об ошибках, предложения и небольшие, сфокусированные pull request.

## Перед началом

1. Проверьте существующие issues, чтобы не создавать дубликат.
2. Для заметного изменения сначала создайте issue и опишите задачу и ожидаемое поведение.
3. Не публикуйте секреты, токены, персональные данные учеников, родителей или сотрудников.
4. Для уязвимостей используйте порядок из [SECURITY.md](SECURITY.md), а не публичный issue.

## Локальная разработка

```bash
npm ci
cp .env_example .env.local
npm run dev
```

Для работы страниц без отправки реальных уведомлений можно оставить интеграционные переменные пустыми. Не используйте реальные заявки в тестовых данных.

## Требования к изменениям

- сохраняйте существующий TypeScript- и React-стиль проекта;
- не меняйте бизнес-логику вместе с несвязанным рефакторингом;
- обновляйте документацию, если меняется настройка или поведение;
- не добавляйте `node_modules`, `.next`, локальные env-файлы и содержимое `data/`;
- перед отправкой выполните проверки:

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

## Pull request

В pull request кратко укажите:

- какую проблему решает изменение;
- что именно изменилось;
- как вы это проверили;
- нужны ли новые переменные окружения или действия при развёртывании.

Делайте один pull request на одну связанную задачу. Участие в проекте подразумевает соблюдение [Кодекса поведения](CODE_OF_CONDUCT.md).
