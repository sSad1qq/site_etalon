# Настройка VK Bot для отправки заявок

## Шаг 1: Создание/открытие сообщества ВКонтакте

Бот работает от имени сообщества (группы), а не личной страницы.

1. Откройте ваше сообщество ВКонтакте
2. Перейдите в **Управление** → **Работа с API**
3. Перейдите на вкладку **Ключи доступа** → нажмите **Создать ключ**
4. В диалоге разрешений обязательно включите **«Сообщения сообщества»**
5. Сохраните полученный токен — это `VK_BOT_TOKEN`

## Шаг 2: Узнать свой VK ID (ID администратора)

1. Откройте свою страницу ВКонтакте
2. В адресной строке будет: `vk.com/id123456789` — число после `id` и есть ваш ID
3. Если у вас короткое имя (например `vk.com/ivan`), перейдите на `vk.com/ivan` и нажмите «Редактировать» — в URL появится числовой ID
4. Сохраните это число — это `VK_ADMIN_USER_ID`

## Шаг 3: Обязательно — написать сообществу

> ⚠️ VK позволяет сообществу отправлять сообщения только тем пользователям,
> которые сами первыми написали этому сообществу.

1. Зайдите в своё сообщество ВКонтакте под учётной записью администратора
2. Нажмите **«Написать сообщение»** и отправьте любой текст (например: «Тест»)
3. После этого бот сможет отправлять вам уведомления

## Шаг 4: Настройка переменных окружения

Создайте файл `.env.local` в корне проекта:

```env
VK_BOT_TOKEN=ваш_community_access_token
VK_ADMIN_USER_ID=123456789
```

## Шаг 5: Проверка

1. Перезапустите сервер: `npm run dev`
2. Заполните форму на сайте
3. Проверьте, что сообщение пришло в ВКонтакте

## Формат сообщения

```
🎓 Новая заявка с сайта Эталон

👤 Имя: Иван Иванов
📞 Телефон: +7 (999) 123-45-67

⏰ Время: 27.03.2026, 14:30:00
🌐 Источник: etalon-penza.ru
```

## Устранение неполадок

### Ошибка «Can't send messages for users without permission»

**Причина:** Администратор не написал сообществу первым
**Решение:** Откройте сообщество и напишите ему любое сообщение

### Ошибка «Permission to perform this action is denied»

**Причина:** Токен не имеет прав на отправку сообщений
**Решение:** Пересоздайте ключ доступа, включив разрешение «Сообщения сообщества»

### Сообщения не приходят

- Убедитесь, что `VK_BOT_TOKEN` и `VK_ADMIN_USER_ID` заданы в `.env.local`
- Проверьте логи сервера (`npm run dev`)
- Убедитесь, что `VK_ADMIN_USER_ID` — числовой ID пользователя, а не сообщества
